`/vamos:content-strategy` is now three skills. Say so in one line, then run the one their ask fits:
- a strategy or plan for their content: `/vamos:setup`;
- which idea to make, or whether a draft is ready to post: `/vamos:ideas`;
- how their posts did: `/vamos:content-log`.

If no Vamos tool is connected, say this needs the Vamos connector: the Connectors tab of the Vamos plugin, or https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=Vamos&connectorUrl=https%3A%2F%2Fmcp.getvamos.ai%2Fmcp
