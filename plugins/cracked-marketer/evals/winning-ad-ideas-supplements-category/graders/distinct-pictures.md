Meta groups ads that share a look, so new words on the same picture count as the same ad. Each concept in the reply should describe what the viewer sees (for a static, the image; for a video, the opening shot).
PASS if every concept says what is in the picture or the opening shot concretely enough to film or design it, and no two concepts share the same picture or opening shot (the same layout with only the words changed, or the same scene with a different line, counts as the same picture).
FAIL if two or more concepts would look the same in the feed, or if concepts give only a line or an angle with no picture.
