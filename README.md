# Vamos plugins

The Vamos plugin for Claude, your AI content strategist: the Vamos connector (`https://mcp.getvamos.ai/mcp`) and seven skills for content research on TikTok, Instagram and YouTube. See [plugins/vamos/README.md](plugins/vamos/README.md).

Every research and writing method lives in the Vamos agent behind the connector, so the skills only gather what a job needs, send Vamos one request, and shape what comes back. Bump `version` in `plugins/vamos/.claude-plugin/plugin.json` on every release, or installed copies don't update.
